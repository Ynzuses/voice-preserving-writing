# Calibration and translation

Read only the section relevant to the selected mode.

## Calibrate from User Edits

When the user supplies comments, tracked changes, rewritten examples, or a manually revised passage, read the whole feedback set before editing. Treat it as evidence about intent, not merely as isolated replacement text.

For each representative change, infer:

1. what reading problem or factual issue it addresses;
2. whether the correction is scientifically required, logically helpful, a stable voice preference, or only locally suitable;
3. which meaning, qualifier, or emphasis must be protected;
4. what semantic pattern, if any, should be checked elsewhere;
5. how the generalized repair will be verified.

Build a compact working profile from repeated signals: directness, usual sentence length, ordinary vocabulary, terminology density, preferred degree of hedging, paragraph order, and use of reader-guiding transitions. If the user says the edits are examples rather than exhaustive, treat that as an explicit instruction to inspect the unannotated remainder.

Search the entire relevant text for justified analogues, including headings, opening and closing paragraphs, lists, captions, and short summaries. Generalize the intent only where the same semantic defect occurs; do not mechanically copy wording or indiscriminately rewrite passages that already work. Preserve authoritative factual corrections, while improving the literal wording when clarity or evidence requires it. Briefly report any important example that was not generalized and why.

## Translation from a Finalized Source

Translate the argument rather than individual sentences. Once the user designates one language version as final, make it the content authority. An older target-language draft may supply already-validated terminology, citations, or formatting, but it must not override the finalized source.

Before translating each paragraph, identify its function: definition, judgment, condition, contrast, evidence, limitation, conclusion, or action. Preserve numbers, units, citations, modality, negation, conditions, and uncertainty. Rebuild the paragraph in natural target-language order, then audit it as a standalone explanation for the target reader. Back-check that no claim, qualification, or required prompt item was added, lost, or strengthened.
